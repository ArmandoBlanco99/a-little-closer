# Two-iPhone playtest

Use two people, two iPhones, and a new room. Record the iPhone model and iOS/browser version for each person. Automated Chromium checks do not establish Safari compatibility or how enjoyable the games feel.

## Connect locally

Start `start-windows.bat` and leave its terminal open. Both phones must use the same Wi-Fi and open `http://COMPUTER-LAN-IP:ACTUAL-PORT`, using the port printed by the launcher. Create the room on one phone and join from the other. Use city-center coordinates if a city is absent from the list.

Local HTTP can test gameplay and download fallback. Test native sharing again over HTTPS after deployment; Safari may require a secure context and a recent user gesture.

## Record the journey

Start the timer when both people choose Ready. Record time spent reading, discussing, playing, or recovering separately where practical. Do not race. The proposed 12–18 minute duration is a hypothesis, not a measured result.

## Phone checks

- Hold steering, release outside the button, and try firing/shielding as copilot. Controls must stop when released or when chat opens.
- Expand/collapse the map during play. Switch between My trail and Partner’s map. Confirm the board, clue, and movement controls are comfortable in portrait orientation.
- Send a clue while the other person's chat is closed. Confirm its unread badge, open chat, type with the keyboard, scroll the conversation, and close it. Check that input and Send remain reachable.
- Pause/resume. Lock one phone for ten seconds, then return. Both players should confirm resuming, with earlier progress intact. Refresh each phone once.
- Try Sound on after tapping it. Confirm visual feedback still makes sense with sound off. Enable iOS Reduce Motion and check the map, flight backdrop, reveals, and celebration.
- Finish each constellation and enjoy the drawing before both continue. At victory, send a heart and confirm the avatars react on both phones.
- Save the postcard on both phones. Check Files/Photos as applicable, and compare names, complete city names, avatars, original distance, four stamps, city map, and UTC date. Try both sharing and canceling the share sheet once HTTPS is available.
- If either person prefers larger text, repeat chat and one board with that phone's usual text/zoom settings.

Report where the game felt dull, demanding, unclear, or one-sided. Tune specific levels from those observations before adding more mechanics.

## After hosting is selected

The intended audience is anyone with the public link. Repeat create/join, chat, disconnect/resume, a complete journey, and postcard sharing with one iPhone on Wi-Fi and the other on cellular. A same-Wi-Fi test cannot establish long-distance deployment reliability.
